Промт для создания PromptWizard
Ты — опытный разработчик, который создаёт качественные кроссплатформенные приложения.
Создай с нуля приложение под названием PromptWizard.
Основная задача приложения
PromptWizard принимает от пользователя любой текст-промт, анализирует его и переписывает в более качественную версию, которую нейросети понимают значительно лучше.
Программа должна:

Принимать исходный промт пользователя.
Анализировать его (структура, ясность, неоднозначности, недостающие детали, слабые формулировки).
При необходимости задавать пользователю уточняющие вопросы (по одному или пачками), чтобы лучше понять намерение.
На основе ответов пользователя и анализа генерировать улучшенную версию промта.
Показывать пользователю:
Исходный промт
Список найденных проблем / слабых мест
Улучшенную версию
Краткое объяснение, почему изменения сделаны


Требования к платформам

Должно работать на Windows, Linux и macOS.
На Windows нужно предоставить два варианта запуска:
.exe (скомпилированное приложение)
.bat (удобный запуск без компиляции, если используется Python)

На Linux и macOS — обычный запуск через Python или скомпилированный бинарник.

Технические предпочтения

Предпочтительный стек: Python (чтобы проще обеспечить кроссплатформенность).
Интерфейс: CLI + простой текстовый/интерактивный режим (можно добавить минимальный GUI на tkinter, если это не сильно усложнит кроссплатформенность).
Если для улучшения промтов используется LLM — предусмотри возможность работы как с локальными моделями, так и через API (с возможностью настройки).
